# Student Portfolio

Plain HTML, CSS and JavaScript. No build step needed.

## Preview locally
Open the folder in VS Code, install **Live Preview** (Microsoft), open `index.html`, click the preview button.

## Add your content
1. Search for `[` in all files (Ctrl+Shift+F) to find every placeholder.
2. Put photos in `images/` (profile.jpg, project1.jpg ...). Then swap the placeholder blocks for the `<img>` lines shown in the HTML comments.
3. Optional resume: save as `assets/resume.pdf` and uncomment the link in the Contact section.

## Publish
Upload the contents of this folder to a public GitHub repo named `portfolio`, then Settings > Pages > Deploy from branch > main > /(root).
